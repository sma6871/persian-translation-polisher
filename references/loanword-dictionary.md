# Salsi-Inspired Loanword Reference (فرهنگ کاربردی واژه‌گزینی بر پایه سالسی)

این راهنما بر اساس اصول پروژه [سالسی (Salsi)](https://github.com/pooooooriya/salsi) و فرهنگ پاسبان، بهینه‌سازی‌شده برای متون مدرن، محصولی و مهندسی تدوین شده است.

> **اصل بنیادین:** «وضوح بر خلوص زبانی اولویت دارد». هرگز واژه‌ای مأنوس و روشن را فدای واژه‌ای مهجور، غریب یا مبهم نکنید.

## ۳. واژگان محافظت‌شده (NEVER TRANSLATE / اصطلاحات غیرقابل تغییر)

این اصطلاحات علمی، صنعتی و فنی **نباید** دستکاری یا معادل‌سازی ناشیانه شوند، زیرا به دقت انتقال مفهوم آسیب می‌زنند:

### الف) اصطلاحات مهندسی نرم‌افزار و معماری
- **API, SDK, CLI, Webhook, REST, GraphQL**
- **Token, JWT, Session, Cookie** (مگر در متن غیرفنی که «نشست» برای session مناسب باشد)
- **Compiler, Interpreter, Runtime**
- **Protocol, Algorithm, Thread, Process** (در سطح سیستم‌عامل)
- **Database, Schema, Index, Query** (در مستندات فنی: کوئری یا پرس‌وجو، دیتابیس یا پایگاه داده)
- **Cache, Buffer, Stack, Heap**
- **Git, Commit, Branch, Merge, Pull Request**
- **Docker, Container, Kubernetes, Pod**
- **Frontend, Backend, Fullstack, DevOps**

### ب) نام‌های خاص و تجاری
- نام برندها و سرویس‌ها: Stripe, Google, GitHub, AWS, Figma, Redis, React, Python.
- اسامی افراد، مکان‌های جغرافیایی، محصولات سخت‌افزاری خاص.

### ج) کدها، مسیرها و پیوندها
- شناسه‌های نرم‌افزاری (`snake_case`, `camelCase`, `CONSTANT`)
- متغیرهای محیطی (`API_KEY`, `NODE_ENV`)
- آدرس فایل‌ها (`/etc/hosts`, `src/index.ts`)
- URLها و پارامترهای پرس‌وجو
- کدهای شورت‌کد یا Markdown tags

## ۴. تله‌های ترجمه کلمه‌به‌کلمه و خطاهای فاحش (False Friends & Literal Translation Traps)

این موارد نمونه‌های بارز خطاهای ماشین هستند که هرگز نباید در ترجمه و ویرایش فارسی راه پیدا کنند:

| اصطلاح انگلیسی | ترجمه ماشینی غلط | معادل طبیعی و حرفه‌ای فارسی | نکته کاربردی و بافت |
| :--- | :--- | :--- | :--- |
| **Pipeline** | خط لوله ❌ | **فرایند، زنجیره پردازش، چرخه، جریان کاری** ✅ | در حوزه نرم‌افزار، هوش مصنوعی، داده و تولید، «خط لوله» اشتباهی مضحک است («خط لوله» منحصراً برای نفت، گاز و آب است). |
| **Thread** | نخ ❌ | **رشته، ترد (`Thread`)، شاخه گفتگو** ✅ | در سیستم‌عامل و پردازش موازی «ترد» یا صورت لاتین `Thread`؛ در پیام‌رسان‌ها و چت «شاخه گفتگو» یا «رشته پیام». |
| **Socket** | پریز ❌ | **سوکت (`Socket`)** ✅ | در شبکه و نرم‌افزار دست‌نخورده می‌ماند. |
| **Bug** | حشره ❌ | **باگ، اشکال نرم‌افزاری، خطا** ✅ | «رفع اشکال» یا «رفع باگ». |
| **Handle / Handler** | دسته / دستگیره ❌ | **مدیریت کردن، پردازش‌گر (`Handler`)** ✅ | «مدیریت خطاها»، «پردازش‌گر رویداد». |
| **Drive** | رانندگی ❌ | **درایو، حافظه، هدایت کردن** ✅ | Cloud Drive: درایو ابری. |
| **Terminal** | پایانه مسافربری ❌ | **ترمینال، خط فرمان** ✅ | در ابزارهای برنامه‌نویسی «ترمینال» یا «خط فرمان». |

## ۵. سطوح انطباق واژگانی (Loanword Strictness Levels)

1. **سطح استاندارد / محصولی (Standard / Product UI - پیش‌فرض):**
   - جایگزینی وام‌واژه‌های تابلو و عامیانه انگلیسی/فرانسوی (سیو -> ذخیره، آپدیت -> به‌روزرسانی، یوزر -> کاربر).
   - حفظ اصطلاحات فنی پایه‌ای که تغییرشان کاربر را گیج می‌کند.

2. **سطح فنی / مستندات توسعه‌دهندگان (Technical / Dev Docs):**
   - حفظ حداکثری اصطلاحات مهندسی با رسم‌الخط انگلیسی یا آوانگاری مرسوم در صورت ضرورت.
   - عدم تبدیل نامتوازن اصطلاحاتی مثل `thread` به «نخ» یا `socket` به «پریز» در جایی که ابهام‌زاست!

3. **سطح بازاریابی و عمومی (Marketing / Copywriting):**
   - روان‌سازی کامل و استفاده از زیباترین و رساترین واژگان زبان فارسی متناسب با حس‌وحال برند.
   - پرهیز از لحن خشک فنی و پرهیز از فخرفروشی با کلمات فرنگی.
